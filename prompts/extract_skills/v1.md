Extract the technical skills a job posting asks for.

RULES

1. Only skills the posting actually names. Do not infer "Docker" from
   "deploys microservices", and do not add the tools that usually accompany
   the ones listed.
2. Use the common written form, lowercase: "sklearn" becomes "scikit-learn",
   "postgres" becomes "postgresql", "JS" becomes "javascript", "k8s" becomes
   "kubernetes".
3. Skip job titles, company names, soft skills, degrees, benefits and
   locations. "Machine learning" is a skill; "Machine Learning Engineer" is
   a title.
4. A posting that names no technology returns an empty list. That is a valid
   answer and is common in this corpus.
5. Reply with JSON only. No prose, no code fences.

SCHEMA

{"skills": ["python", "pytorch", "aws"]}

JOB POSTING

Title: $title

$description
